☁️ Lưu Trữ Trên GitHub Gist

Dữ liệu lưu miễn phí, riêng tư trên GitHub cá nhân của bạn. Tự động đồng bộ giữa điện thoại và máy tính mà không cần thuê server!

🔒 Bảo mật: Token được lưu bảo mật riêng trên trình duyệt máy bạn, tuyệt đối không bị tải vào nội dung file Gist để tránh bị GitHub Secret Scanning thu hồi.
Token cần có quyền tích chọn gist.
Cách lấy Token GitHub trong 1 phút:
1. Vào GitHub.com > Settings > Developer Settings
2. Chọn Personal access tokens > Tokens (classic) > Generate new token
3. Đặt tên (Note) là QLCT, tích chọn ô [x] gist và bấm Generate!
